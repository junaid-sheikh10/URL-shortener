# URL Shortener

Read `docs/url-shortener-spec.md` first, especially section 0 ("Instructions for Claude Code"). Follow it for every task.

Key rules from the spec:
- This is a learning project. Work one milestone at a time (spec section 9) and stop for review after each.
- Explain what and why before writing code; summarize and say what to verify afterwards.
- Raw SQL only (no ORM). Simple, readable code.
- Ask before adding any dependency not listed in the spec.
- Keep `NOTES.md` updated with decisions and benchmark numbers.
